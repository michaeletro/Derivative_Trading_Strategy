The raw ensemble estimates YES settlement probability. With sensitivity haircut h, the displayed range is L = max(0, p − h) to U = min(1, p + h). Entry sizing uses pYES = L and pNO = 1 − U. These are separate directional stress estimates and need not sum to one.

Only earlier admitted residuals define the reference mean and sample standard deviation. tailNO = (1 + count(rprior ≤ rₜ))/(N + 1)
%K = 100(rₜ − min(r))/(max(r) − min(r)), using the prior window plus the current residual for the range.

The held YES side can exit when z ≤ zexit; held NO can exit when z ≥ −zexit. Fees and depth still constrain execution. Tail ranks describe historical rarity; serial dependence and repeated monitoring prevent interpreting the threshold as a validated false-signal rate.

Monte Carlo counts settlement outcomes
p̂ = M⁻¹ Σⱼ 1{Aⱼ satisfies the contract}

For each of M paths, the model completes the CF settlement average A while holding already observed settlement ticks fixed. The estimate is the fraction of simulated wins under the contract comparator. Its numerical sampling interval concerns simulation precision under that frozen model; it does not include fitting error or shared misspecification.

    Diffusion probability and Taylor approximation
    p = Φ((μA − K)/σA) · Δp ≈ δΔS + ½γ(ΔS)² + θΔt

    With positive conditional variance, the frozen local additive diffusion gives a Gaussian settlement average with mean μA and standard deviation σA. The Gaussian CDF Φ converts its distance from the strike K to a model probability. Dollar volatility is frozen while evaluating a price shock.
